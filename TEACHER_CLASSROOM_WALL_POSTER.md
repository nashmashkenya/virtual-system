# ElimuPawa Classroom Wall Poster

## Teach With Confidence

Keep this visible during every live class.

---

## Before Class

- [ ] Open Teacher meeting room
- [ ] Camera on
- [ ] Mic on
- [ ] Chat on (if needed)
- [ ] Hands on (if needed)
- [ ] Learners tab checked

---

## During Class

- [ ] Watch **Learners** for waiting students
- [ ] Watch **Activities** for raised hands and Q&A
- [ ] Turn on **Slow mode** if chat is noisy
- [ ] Turn **Chat** or **Hands** off briefly if class needs focus

---

## Waiting Room

- Approve = let student in
- Deny = do not admit

---

## Quick Controls

- Camera on/off
- Mic on/off
- Chat on/off
- Slow mode
- Hands on/off
- Learners
- Activities
- More controls (advanced only)
- Leave

---

## Broadcast Class (YouTube) Quick Setup

- [ ] Set Delivery mode to **Broadcast**
- [ ] Paste YouTube live/watch link
- [ ] Start stream in YouTube Studio 5-10 min early
- [ ] Keep students in ElimuPawa Classroom for chat and control

---

## If Something Is Wrong

- Refresh: `Ctrl + F5`
- Re-check Chat / Hands / Slow mode
- Sign out and sign in again

---

## End Class

- [ ] Final reminder to learners
- [ ] Optional: Chat off
- [ ] Click **Leave**

---

## Print Tip

- Press `Ctrl + P`
- Choose **Save as PDF**
- Portrait, default margins, 95-100% scale
